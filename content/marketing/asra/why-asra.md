Here’s a sharper X post version:

A lot of the recent “agent” papers are solving important pieces of the puzzle:

memory,
routing,
architecture search,
agent harnesses,
verification loops,
multi-agent orchestration,
interpretability, etc.

But ASRA is fundamentally different.

Most of these systems still assume:
the actions already have meaning,
the environment semantics are known,
and the world is largely predefined.

ASRA is focused on something deeper:

learning hidden action semantics from interaction itself.

Not just:
“which action gives reward?”

But:
“What does this action actually DO to the world?”

That means:
state differencing,
transition analysis,
causal structure inference,
semantic abstraction,
replay systems,
world-model evolution,
intervention reasoning,
and autonomous mechanism discovery.

Decision Biology extends this into biology:
treating cells as adaptive decision-making systems operating under uncertainty.

Nature Foundation Models extends this even further:
toward scientific intelligence that can understand, simulate, intervene in, and discover mechanisms across biology, chemistry, physics, and environmental systems.

Many current papers optimize agent infrastructure.

ASRA is trying to build the cognitive substrate for scientific reasoning itself.
