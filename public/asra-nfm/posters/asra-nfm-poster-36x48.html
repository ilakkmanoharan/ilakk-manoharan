Central research question. Can an agent learn unfamiliar environments efficiently by treating actions as scientific interventions, maintaining competing explanations, and explicitly modeling the mechanisms that produce observed changes?

Motivation

  • Pattern recognition may predict outcomes without discovering mechanisms.
  • Purely symbolic systems can be brittle when perception is uncertain.
  • Passive learning cannot efficiently resolve ambiguity in novel interactive environments.
  • Agents must learn what actions mean, infer goals, distinguish correlation from mechanism, and plan with incomplete knowledge.

Foundational transition — Before → Action → After

Tt = (st, at, st+1)    Δt = Diff(st, st+1)

st structured state before · at action/intervention · st+1 resulting state · Δt observed effect.

Transitions provide evidence about action semantics, environmental rules, causal mechanisms, invariants, goals, and terminal conditions.

Fig. 1 — Transition evidence unit for mechanism learning.

Object-centric reasoning

State as entities and relations — not only pixels or a global novelty vector.

Object: identity, type, color, shape, position, attributes, history
Relations: adjacent-to · inside · aligned-with · blocking · approaching · connected-to
Effect(a, oi, rij, ct) → Δoi

Detected objects and relations must influence hypothesis generation, transition prediction, experiment selection, action scoring, and planning.

Fig. 2 — Binding interventions to object–relation structure.

Memory

Episodic (runs) · transition (before–action–after) · semantic (concepts/rules) · procedural (successful sequences) · failure (contradicted rules) · experiment (hypotheses, configs, results, conclusions).

Architecture

Fig. 3 — Observation → perception → state → intervention → transition analysis → hypotheses → hybrid world model → information gain → planning → next action, with feedback into memory and belief revision. Styling: neural (cyan), symbolic (amber), evidence (green), planning (violet).

Tabby — Questions

Identifies uncertainty about actions, mechanisms, goals, objects, relations; proposes discriminating questions and interventions. Functional reasoning module — not necessarily a separate language model.

Grubby — Evidence

Answers from recorded observations and transitions: support, contradictions, invariants, and counterexamples.

Sam — Decisions

Chooses whether to explore, test a hypothesis, or execute a goal-directed plan.

Hypothesis management

Ht = {h1, h2, …, hk}
Score(h) = Accuracy(h) + α Coverage(h) − β Complexity(h) − γ Contradictions(h)

H1 ACTION_2 moves every red object.   H2 moves the object adjacent to the agent.   H3 moves the selected object when the path is clear.

Prefer hypotheses that predict accurately, explain more evidence, remain simple, and survive attempted falsification. Interventions distinguish these possibilities.

Fig. 4 — Competing falsifiable mechanisms.

Active experimentation

at* = argmaxa [ IG(a; Ht) + λ P(progress | a) − μ Risk(a) − ν Cost(a) ]

An action is valuable if it advances the inferred objective or reveals which world-model hypothesis is correct.

Applications & methodology

Testbed: interactive ARC-AGI-style environments. Broader: novel envs, autonomous ML experimentation, scientific discovery, robotics, biological decision systems, physical AI. Adapters share one adaptive scientific-reasoning core.

Baselines: random · heuristic · neural-only · symbolic-only · hybrid · hybrid + active IG.

Ablations: −object relations · −hypothesis memory · −neural WM · −active experiment · −failure memory · −complexity penalty.

Metrics: success, score, action efficiency, prediction accuracy, mechanism recovery, goal inference, IG/action, calibration, compute, generalization.

Main research claim (hypothesis)

An object-centric neuro-symbolic agent with explicit hypothesis management and active intervention can learn novel mechanisms more accurately and with fewer actions than passive, neural-only, and symbolic-only baselines.

Contributions

  1. Transition-centered learning from before–action–after evidence
  2. Explicit separation of action semantics, mechanisms, and goals
  3. Object-centric causal representation
  4. Competing, falsifiable symbolic hypotheses
  5. Hybrid neural + symbolic world modeling
  6. Information-seeking intervention selection
  7. Interpretable evidence and decision traces
  8. Reusable architecture for interactive reasoning and scientific experimentation
