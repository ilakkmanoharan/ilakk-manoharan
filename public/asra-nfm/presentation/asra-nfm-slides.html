Definition

Not a predictor wrapper — an adaptive reasoner

A neuro-symbolic architecture that learns world dynamics through intervention, represents discovered mechanisms explicitly, and plans under uncertainty.

  • Observes structured environments
  • Performs interventions and records before–action–after transitions
  • Maintains competing hypotheses
  • Selects actions that reduce uncertainty or advance an inferred goal
Central research question

Can an agent learn unfamiliar environments efficiently by treating actions as scientific interventions, maintaining competing explanations, and explicitly modeling the mechanisms that produce observed changes?

Motivation

Why hybrid active science?

  • Pattern recognition can predict without discovering mechanisms
  • Purely symbolic systems break under uncertain perception
  • Passive learning is inefficient in novel interactive worlds
  • Need: action meaning, goals, mechanisms, planning with incomplete knowledge

Foundational unit

Before → Action → After

Tt = (st, at, st+1)    Δt = Diff(st, st+1)
  • st — structured state before the action
  • at — action / intervention
  • st+1 — resulting structured state
  • Δt — observed effect of the intervention

Evidence for action semantics, rules, mechanisms, invariants, goals, terminals.

Architecture

Closed scientific loop

Neural · symbolic · memory/evidence · planning — with feedback into hypothesis revision.

Reasoning organization

Three functional modules

Tabby — Questions

Identifies uncertainty; proposes discriminating interventions.

Grubby — Evidence

Supports, contradictions, invariants, counterexamples from transitions.

Sam — Decisions

Explore, test, or execute a goal-directed plan.

Modules — not a requirement for three separate language models.

Mechanisms

Competing falsifiable hypotheses

Ht = {h1 … hk}
Score(h) = Acc + α Cov − β Complexity − γ Contradictions
  • H1: ACTION_2 moves every red object
  • H2: moves the object adjacent to the agent
  • H3: moves the selected object when the path is clear

Interventions distinguish these possibilities.

Hypothesis

Main research claim

An object-centric neuro-symbolic agent with explicit hypothesis management and active intervention can learn novel mechanisms more accurately and with fewer actions than passive, neural-only, and symbolic-only baselines.

Presented as a hypothesis until validated by controlled evaluation.
