Config — the control panel

"The recipe card"

A YAML settings file tells the generator everything about one run: which skillset, where the state machine lives, how many rows to make, which companies to use, and whether to call an LLM. It loads and validates settings — it does not generate conversations.

Layer 0 is a YAML file you pass to voxtune-generate --config …. It is the control panel for the whole run — settings only, no dialogue generation.
  • Reads one YAML file from disk
  • Validates required fields (paths exist, percentages sum correctly)
  • Produces a GeneratorConfig Python object the other layers read
  • Fails fast — bad config stops the run before wasting GPU time
It does not walk the state machine, write caller/agent words, build messages[], call sipagent runtime, or write JSONL. Those are Layers 1–5.
File: generator/config/examples/receptionist-demo.yaml
  • generation.num_rows — total row count (e.g. 500)
  • distribution — happy 70% / edge 20% / failure 10%
  • companies — three embedded business profiles (Acme, Bright, Summit)
  • paraphrase.mode: template — phrase book only, no GPU
