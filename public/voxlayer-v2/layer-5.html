Layer 5

Writer — the filing cabinet

"Save one JSONL line per example"

Layer 5 takes each finished row from Layer 3 and appends one line to a JSONL file. When the run finishes, you have a dataset ready for voxtune-validate and Unsloth training. It does not plan, walk, speak, or wrap — it only persists.

Shipped — generate.py write loop in voxtune main

Layer 5 is the filing clerk — it serializes each assembled training row and appends one JSON line to the output file.
  • Receive assembled row from Layer 3 (in memory)
  • Serialize to compact JSON (UTF-8, one object)
  • Append one line to output.path from Layer 0 config
  • Repeat for every work unit Layer 1 scheduled
  • Flush / close file when run completes
Typical: inside voxtune-generate main loop after PromptAssembler.build_row(...).
JSONL = JSON Lines — one JSON object per line. Benefits: streaming (write row 1 before row 2000 exists), easier resume/split, training loaders ingest line by line, no single giant array in git.
  • messages[] — model input (system + conversation with runtime badges)
  • output — model label (target assistant line + next_state)
  • meta — provenance (scenario_id, path_class, state, next_state, company_slug…)
