Layer 2

Traversal — stage setup

"Get sipagent into the right call state"

Before we record the target moment of a call, Layer 2 puts sipagent's runtime in the correct state (e.g. CONFIRM_SLOTS) with slots filled. It walks the state machine in code — it decides what happens. It does not write the final pretty words (Layer 4).

Layer 2 is the stage crew — it gets sipagent's runtime into the right call state with the right slots filled before the target training turn is recorded.
  • Layer 1 picks a script (e.g. happy:take_message) from scenarios.py
  • CallSimulator in simulator.py runs the entire call turn by turn
  • Each turn becomes its own JSONL row (turn_index 1, 2, 3…)
  • Many rows share one scenario_id
  • Templates supply words; assembler builds messages[] per turn
  • Training must match production slot rules and transitions
  • [skillset_runtime_context] JSON in messages[] must be honest
  • Validator checks next_state against what the SM allows

To reach e.g. CONFIRM_SLOTS, we need earlier turns (classify intent → take message → fill slots). Those turns become history[]. In v2, one JSONL row = one target edge, but messages[] can contain prefix turns inside the same row for realistic context.
  • cold_open — messages[] starts at INTENT_CLASSIFY (full path in prefix)
  • random — sometimes shorter entry, still legal path to from_state
  • fixed — always same depth for debugging
